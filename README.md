\# radish-admin-web

萝卜快跑后台管理前端，基于 Gin-Vue-Admin 脚手架改造，Vue3 + Vite。



\## ✨ 技术栈

\- Vue3

\- Vite

\- Element Plus

\- Pinia

\- Axios

\- JavaScript



\## 📋 项目介绍

萝卜快跑后台管理系统，负责司机管理、车辆管理、订单管理、用户管理等后台业务。



\## 💻 环境

Node >= 16



\## 📦 安装依赖

```bash

npm install

```



\## 🚀 启动



```

\# 开发环境

npm run dev

\# 打包上线

npm run build

```



\## 📁 目录说明



```

src

├── api          # 接口请求

├── views        # 页面

├── components   # 公共组件

├── router       # 路由

├── store        # pinia状态

├── utils        # 工具函数

└── permission.js # 权限控制

```
