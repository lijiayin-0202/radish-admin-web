# 任务 03：模块 3 运营区域管理页面

## 目标

提供运营区域的查询、新增、编辑与状态管理页面，通过后台 BFF 调用模块 3 能力。

## 约束

- 仅使用 `src/utils/request.js` 请求后台 `/api/module3/*`。
- 编辑区域不得传递 `areaCode`。
- 区域状态固定为临时关闭（0）、运营中（1）、停运（2）。
