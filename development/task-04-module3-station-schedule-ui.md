# 任务 04：模块 3 站点与运营时段页面

## 目标

提供站点的查询、新增、编辑、启停，以及运营区域时段的安全回填与覆盖保存。

## 约束

- 站点查询必须先选运营区域；名称筛选和分页在当前区域数据中完成。
- 编辑站点不能显示或提交 `serviceAreaId`、`stationCode`。
- 星期规则仅允许 1-7；特殊日期规则固定星期 0；跨午夜时段可保存。
