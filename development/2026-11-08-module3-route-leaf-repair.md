# 模块 3 运营调度页面空白修复记录

- 状态：开发完成，待浏览器验收
- 日期：2026-11-08

## 现象

点击“出行运营 → 运营调度管理”后，菜单能够选中，但右侧页面曾出现空白，并在浏览器控制台提示路由记录没有组件。

## 根因

后台历史菜单数据可能为“运营调度管理”附带了子菜单或重定向。前端动态路由转换时会将这种记录当作父级菜单处理，导致实际页面组件没有被作为叶子页面正确注册。

## 修改

- `src/utils/module3Route.js`：注册运营调度管理页面时主动移除历史 `children` 与 `redirect`，固定注册为携带页面组件的叶子路由。
- `test/module3Route.test.mjs`：增加“旧菜单误带子项”场景的路由回归测试。

## 验证

- JavaScript 源文件语法检查通过。
- 后台模块 3 定向 Go 测试通过。
- 前端生产构建待在本机终端执行；自动化环境限制 Vite 拉起子进程，未将该环境限制当作业务构建失败。

## 浏览器验收步骤

1. 重新启动前端并登录后台。
2. 点击“出行运营 → 运营调度管理”。
3. 确认显示“运营区域”和“站点管理”两个页签。
4. 验证区域、站点的查询、新增、编辑和启停。
